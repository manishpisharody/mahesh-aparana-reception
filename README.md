# Mahesh & Aparna — Wedding Invitation

A responsive single-page wedding invitation built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly, or from this folder run:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Assets and customization

- Couple photos are in `assets/images/`.
- To enable background music, add an MP3 at `assets/music/wedding-music.mp3`.
- Map links are real Google Maps search links in `index.html`; replace them with exact shared location URLs when available.
- Colors and typography are centralized as CSS variables at the top of `styles.css`.

## Static deployment

The site can be deployed unchanged to GitHub Pages, Netlify, Cloudflare Pages, or any static web host. Publish the repository root as the site directory.
